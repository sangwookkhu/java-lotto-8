# java-lotto-precourse
## 기능 구현 목록

### Model

#### Lotto (로또 티켓)
- [x] 6개의 숫자로 로또 번호를 생성
- [x] 로또 번호가 6개인지 검증
- [x] 로또 번호가 1~45 범위인지 검증
- [x] 로또 번호에 중복이 없는지 검증
- [x] 로또 번호를 오름차순으로 정렬하여 반환
- [x] 당첨 번호와 일치하는 개수를 반환
- [x] 보너스 번호 포함 여부를 확인

#### LottoGenerator (로또 생성기)
- [ ] 구매 금액을 입력받아 로또 개수를 계산
- [ ] 계산된 개수만큼 로또를 자동 생성
- [ ] `Randoms.pickUniqueNumbersInRange()`를 사용하여 랜덤 번호를 생성

#### WinningNumbers (당첨 번호)
- [x] 당첨 번호 6개를 저장
- [x] 보너스 번호 1개를 저장
- [x] 당첨 번호가 1~45 범위인지 검증
- [x] 당첨 번호에 중복이 없는지 검증
- [x] 보너스 번호가 당첨 번호와 중복되지 않는지 검증

#### Rank (당첨 등수 Enum)
- [x] 1등: 6개 일치, 2,000,000,000원
- [x] 2등: 5개 일치 + 보너스 일치, 30,000,000원
- [x] 3등: 5개 일치, 1,500,000원
- [x] 4등: 4개 일치, 50,000원
- [x] 5등: 3개 일치, 5,000원
- [x] 꽝: 2개 이하 일치
- [x] 일치 개수와 보너스 일치 여부로 등수를 판별
- [x] 등수별 상금을 반환

#### LottoResult (로또 결과)
- [ ] 구매한 모든 로또의 당첨 결과를 저장
- [ ] 각 등수별 당첨 개수를 계산
- [ ] 총 상금을 계산
- [ ] 수익률을 계산 (총 상금 / 구매 금액 * 100)
- [ ] 수익률을 소수점 둘째 자리에서 반올림

### View

#### InputView (입력)
- [ ] 구매 금액을 입력받음
- [ ] 당첨 번호를 입력받음 (쉼표로 구분)
- [ ] 보너스 번호를 입력받음
- [ ] `Console.readLine()`을 사용

#### OutputView (출력)
- [ ] 구매한 로또 개수를 출력
- [ ] 구매한 로또 번호 목록을 출력 (오름차순 정렬)
- [ ] 당첨 통계를 출력
  - [ ] 3개 일치 (5,000원) - n개
  - [ ] 4개 일치 (50,000원) - n개
  - [ ] 5개 일치 (1,500,000원) - n개
  - [ ] 5개 일치, 보너스 볼 일치 (30,000,000원) - n개
  - [ ] 6개 일치 (2,000,000,000원) - n개
- [ ] 총 수익률을 출력
- [ ] 에러 메시지를 "[ERROR]"로 시작하여 출력

### Controller

#### LottoController (게임 진행 컨트롤러)
- [ ] 게임 전체 흐름을 제어
- [ ] 구매 금액을 입력받아 검증
  - [ ] 1,000원 단위인지 검증
  - [ ] 양수인지 검증
- [ ] 로또를 생성하고 출력
- [ ] 당첨 번호를 입력받아 검증
  - [ ] 6개의 숫자인지 검증
  - [ ] 쉼표로 구분되어 있는지 검증
  - [ ] 1~45 범위인지 검증
  - [ ] 중복이 없는지 검증
- [ ] 보너스 번호를 입력받아 검증
  - [ ] 1~45 범위인지 검증
  - [ ] 당첨 번호와 중복되지 않는지 검증
- [ ] 당첨 결과를 계산하고 출력
- [ ] 잘못된 입력 시 해당 부분부터 다시 입력받음
- [ ] `IllegalArgumentException` 발생 시 에러 메시지를 출력하고 재입력을 받음

### 예외 처리
- [ ] 구매 금액이 1,000원 단위가 아닌 경우
- [ ] 구매 금액이 양수가 아닌 경우
- [ ] 로또 번호가 6개가 아닌 경우
- [ ] 로또 번호가 1~45 범위를 벗어난 경우
- [ ] 로또 번호에 중복이 있는 경우
- [ ] 당첨 번호 입력 형식이 잘못된 경우
- [ ] 보너스 번호가 당첨 번호와 중복되는 경우
- [ ] 숫자가 아닌 값을 입력한 경우
